# Bienvenue dans la documentation BarTime

**BarTime** simplifie la gestion de la buvette de votre club : ventes,
paiements, comptes adhérents, statistiques et comptabilité — dans une
application pensée pour le terrain (buvettes, journées de match,
événements).

## Pour qui ?

BarTime s'utilise selon trois rôles :

| Rôle                             | Ce qu'il fait avec BarTime                                                                                      |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Administrateur** (association) | Crée les produits, gère les adhérents et les rôles, suit les ventes, exporte la comptabilité, gère l'abonnement |
| **Barman**                       | Encaisse les ventes (carte, espèces, QR, crédit), recharge les soldes                                           |
| **Adhérent**                     | Consulte son solde, son historique et présente son QR code pour payer                                           |

:::tip
Vous n'êtes pas sûr de votre rôle ? L'administrateur est le compte qui a
créé l'association sur BarTime — c'est lui qui invite les autres.
:::

1. [**Démarrage rapide**](./quick-start) — créer votre compte, découvrir

3. [**Abonnement**](./abonnement) — essai, formules, achat et résiliation.
4. [**FAQ**](./faq) — les réponses aux questions les plus fréquentes.
