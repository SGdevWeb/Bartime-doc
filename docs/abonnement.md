# Abonnement

## Votre essai : 2 mois gratuits

Dès la création de votre association, un **essai de 2 mois** démarre
automatiquement — **toutes les formules sont incluses**, sans carte
bancaire et sans engagement.

Vous pouvez utiliser BarTime librement pendant toute la durée de l'essai.
Son statut est visible dans **Paramètres → Facturation**.

## Les formules

| Formule       | Prix                                   | Pour qui                                       |
| ------------- | -------------------------------------- | ---------------------------------------------- |
| **Mensuelle** | **2,99 € / mois**                      | Les clubs qui veulent démarrer sans engagement |
| **Annuelle**  | **24,99 € / an** (soit 2 mois offerts) | Les clubs qui veulent le meilleur tarif        |

Les deux formules donnent **accès à toutes les fonctionnalités** : il n'y
a aucun palier ni fonction réservée.

## Comment souscrire ?

1. **Paramètres → Facturation** ;
2. Choisissez la formule puis **S'abonner** ;
3. Le paiement se fait **dans l'app via l'App Store** (Apple Pay, carte
   enregistrée…) — aucune donnée bancaire n'est transmise à BarTime ;
4. L'abonnement est actif **immédiatement**.

:::info
La version **Android (Google Play)** de l'app arrive très prochainement :
l'achat pourra alors se faire depuis Google Play avec les mêmes
formules.
:::

:::note
Pourquoi dans l'app ? Les achats intégrés sont exigés par Apple pour
les abonnements numériques — c'est aussi la voie la plus sûre : le
paiement est géré par Apple, avec les protections du store.
:::

## L'essai se termine, et après ?

À la fin des 2 mois sans abonnement souscrit, l'accès aux fonctions de
**gestion et d'encaissement est suspendu** jusqu'à la souscription :
rien n'est supprimé — soldes, historique et produits sont conservés. Il
suffit de souscrire depuis **Paramètres → Facturation** pour tout
retrouver.

## Factures et reçus

- Les **factures d'abonnement** s'affichent dans **Paramètres →
  Facturation** ;
- Les **reçus Apple** sont consultables dans l'historique d'achats de
  votre compte App Store.

## Résilier ou changer de formule

- **Résiliation / changement** : depuis votre iPhone → **Réglages →
  [votre nom] → Abonnements → BarTime** (« Gérer »). L'abonnement reste
  actif **jusqu'à la fin de la période déjà payée** ;
- **Changer mensuel ↔ annuel** : faites-le depuis les réglages
  d'abonnement de votre téléphone (Apple gère le changement de formule).
