# Guide barman

Le mode **barman** est celui des jours de buvette : rapide, efficace,
une main sur le téléphone.

:::info
Votre administrateur vous a invité par email ? Activez votre compte puis
utilisez l'onglet **Carte** : c'est le cœur de votre métier de barman.
:::

## La Carte (accueil du barman)

- Les produits sont classés par **catégories**.
- **Touchez un produit** pour l'ajouter au panier.
- L'onglet **Commande** affiche le **nombre d'articles** en cours.
- Un **+** / **–** sur l'article ajuste la quantité (dans la commande).

:::tip
En pleine affluence, gardez le panier court et encaissez au fur et à
mesure : c'est plus rapide qu'un grand panier du soir.
:::

## La commande et l'encaissement

1. Ouvrez **Commande**, vérifiez le panier, puis **Encaisser**.
2. Choisissez le ou les **modes de paiement** :

| Mode        | Fonctionnement                                             |
| ----------- | ---------------------------------------------------------- |
| **Espèces** | Saisissez la monnaie reçue → le **rendu** s'affiche        |
| **Carte**   | Validez après le passage sur le terminal du club           |
| **QR code** | Scannez le QR code affiché sur le téléphone de l'adhérent  |
| **Crédit**  | Débit direct du solde de l'adhérent (il peut être négatif) |

3. Les **paiements mixtes** sont possibles : combinez deux modes (ex.
   10 € espèces + le reste carte) — les parts doivent exactement
   compléter le total.
4. La vente est enregistrée, le panier se vide et l'adhérent retrouve
   son historique immédiatement.

### Vendre à un adhérent

- **QR** : scannez son code (l'appareil photo demande l'autorisation la
  première fois) ;
- **Crédit** : sélectionnez l'adhérent dans la liste (recherche par
  nom) — il faut avoir été invité et avoir activé son compte.

### Vendre sans adhérent

Les paiements **espèces** et **carte** fonctionnent sans sélectionner
d'adhérent : idéal pour les passants et les invités.

## Recharge de solde

Onglet **Recharge** :

1. Recherchez l'adhérent par **nom** (ou scannez son QR).
2. Indiquez le **montant** et le mode (espèces ou carte).
3. Validez : le solde est crédité et l'opération apparaît dans
   l'historique de l'adhérent.

:::tip
La recharge en espèces alimente le tiroir-caisse : pensez à l'encaisser
dans le même sens que les ventes pour que le comptage de fin de journée
corrige.
:::

## Mode cadeau

Si l'administrateur a activé le **mode cadeau** dans les réglages, un
interrupteur **« Offrir »** apparaît dans la commande : les produits
ajoutés sont enregistrés à0 € (lotos, tombolas, animations).

## Session de caisse (mode avancé uniquement)

Si l'association utilise le **mode de caisse avancé** :

- À l'ouverture : l'app vous demande d'**ouvrir une session** avec le
  **fond de caisse** ;
- À la fermeture : saisissez le **montant compté** — l'écart est
  calculé ;
- En **mode simple** (défaut) : aucune session à gérer, encaissez
  directement.
