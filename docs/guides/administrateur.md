# Guide administrateur

En tant qu'**administrateur** (compte « association »), vous avez accès à
toutes les fonctions de gestion depuis l'onglet **Paramètres**.

## Gestion des produits et catégories

**Paramètres → Gestion des produits**

- **Ajouter** : nom, prix, catégorie (obligatoires), éventuellement une
  description.
- **Modifier / supprimer** : icônes sur chaque ligne.
- Les produits apparaissent immédiatement dans la **Carte** des barmans.

**Paramètres → Catégories**

- Les catégories structurent l'affichage de la carte (une catégorie par
  section).
- À la création de l'association, 7 catégories par défaut sont générées
  (Bières, Softs, Vins, Apéritifs, Snacks, Boissons chaudes, Autres).

:::tip
Gardez une carte courte et lisible : 15 à 25 produits maximum facilitent
l'encaissement des jours d'affluence.
:::

## Gestion des adhérents et des rôles

**Paramètres → Gestion des adhérents**

| Action                  | Comment                                                                        |
| ----------------------- | ------------------------------------------------------------------------------ |
| **Ajouter un adhérent** | « Ajouter » → nom + email → invitation par email avec lien d'activation (48 h) |
| **Rechercher**          | Par nom pour vérifier un solde rapidement                                      |
| **Modifier**            | Nom, email de l'adhérent                                                       |
| **Supprimer**           | Retire l'adhérent de l'association. Visible dans l'onglet **Anciens membres**  |

**Rôles disponibles** (définis à l'ajout ou à la modification) :

- **association** (administrateur) : accès complet, y compris facturation
  et paramètres ;
- **barman** : encaissement, carte, commande, recharge — pas la gestion ;
- **adhérent** : son espace personnel (solde, historique, QR).
- Permission **« gestion du bar »** : donne l'accès barman à un adhérent
  sans changer son rôle.

**Transférer l'administration** : **Paramètres → Compte → Transférer
l'administration** — indiquez l'email du nouvel admin et votre mot de
passe. Votre accès administrateur est retiré (votre compte adhérent est
conservé).

**Anciens adhérents** : **Paramètres → Gestion des adhérents → onglet
« Anciens membres »** — permet de rembourser le solde d'un adhérent
parti ou de le réactiver dans l'association.

## Suivi des ventes

- **Paramètres → Statistiques et ventes** : ventes par période, produits
  phares, répartition des modes de paiement.
- **Paramètres → Historique des transactions** : liste complète avec
  filtres.
- **Paramètres → Gestion de caisse** : vue des sessions (si le mode
  avancé est activé) et réglages de caisse.

## Réglages de l'association

**Paramètres → Réglages de l'association** :

- **TVA** : activation et affichage sur les produits ;
- **Mode de caisse** : _simple_ (par défaut, aucune session à gérer) ou
  _avancé_ (ouverture/fermeture de session avec comptage).
- **Mode offre** : possibilité d'offrir des consommations.
- **Modes de paiement acceptés** : carte bancaire, crédit, mode cadeau ;

## Comptabilité : exports

**Paramètres → Exports comptables** :

- Exports **XLSX** : détaillé, mensuel, annuel ;
- **Rapport comptable** synthétique ;
- Export d'une **session de caisse** (mode avancé).

Les fichiers sont générés immédiatement et peuvent être envoyés tels
quels au comptable du club.

## Facturation et abonnement

**Paramètres → Facturation** :

- Statut de votre **essai** ou de votre abonnement ;
- Choix de la formule (**mensuelle** ou **annuelle**) ;
- Achat de l'abonnement directement dans l'app (App Store) ;
- Historique des factures disponible directement sur votre compte Apple.

Tout est détaillé dans le guide [Abonnement](../abonnement).

## Compte et sécurité

**Paramètres → Compte** :

- Modifier nom, email et mot de passe ;
- **Supprimer mon compte** (action définitive et irréversible —
  l'anonymisation conserve l'historique des transactions de
  l'association).
