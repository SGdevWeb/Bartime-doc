# FAQ

## Essai et abonnement

### Que se passe-t-il après les2 mois d'essai ?

Si aucun abonnement n'est souscrit à la fin de l'essai, l'accès aux
fonctions de gestion et d'encaissement est **suspendu** (rien n'est
supprimé). Souscrivez depuis **Paramètres → Facturation** pour
rétablir l'accès instantanément. Voir [Abonnement](./abonnement).

### Comment résilier mon abonnement ?

Depuis votre iPhone : **Réglages → [votre nom] → Abonnements →
BarTime**. L'abonnement reste actif jusqu'au terme de la période payée.

### Pourquoi le paiement passe par l'App Store ?

Les achats intégrés sont obligatoires pour les abonnements numériques
sur iOS — et le paiement est traité par Apple : BarTime ne voit jamais
vos données bancaires.

## Adhérents et invitations

### Comment inviter un adhérent ?

**Paramètres → Gestion des adhérents → Ajouter** : nom et email →
l'invitation part avec un lien d'activation valable48 h.

### L'adhérent n'a pas reçu l'email d'invitation

Vérifiez les spams, puis demandez le renvoi depuis la fiche de
l'adhérent (l'administrateur peut renvoyer le lien d'activation).

### L'adhérent n'a pas d'iPhone — est-ce bloquant ?

Non pour les paiements **espèces et carte** : le barman encaisse sur le
compte de l'adhérent en le recherchant par nom. Le **QR code et le
crédit** nécessitent l'app sur le téléphone de l'adhérent — la version
**Android arrive très prochainement**.

### L'adhérent a changé de téléphone ?

Il installe BarTime et se connecte avec le **même email et mot de
passe** : solde, historique et QR code sont restaurés.

## Fonctionnement du club

### Puis-je gérer plusieurs associations avec un compte ?

Oui : un compte, plusieurs structures — utilisez le sélecteur
d'association dans vos **Paramètres**. Voir
[Guide adhérent](./guides/adherent).

### Comment fonctionne le crédit (« payer à crédit ») ?

Le barman débite le solde de l'adhérent, qui peut devenir légèrement
négatif : c'est un crédit accordé par le club, régularisé à la
prochaine recharge. Idéal pour les habitués.

### Le mode de caisse, simple ou avancé ?

- **Simple** (défaut) : aucune session, on encaisse directement ;
- **Avancé** : ouverture avec fond de caisse, fermeture avec comptage
  et calcul d'écart.

Réglable dans **Paramètres → Réglages de l'association**.

### Comment exporter la comptabilité ?

**Paramètres → Exports comptables** : CSV, XLSX (détaillé, mensuel,
annuel) et rapport comptable — prêts pour le trésorier ou le
comptable.

## Données et confidentialité

### Mes données sont-elles exportables ?

Oui : tous les exports sont disponibles depuis l'app, à tout moment.
Vous pouvez aussi **supprimer votre compte** (Paramètres → Compte) —
l'anonymisation conserve l'historique des transactions de l'association.
